# 多源账单解析

把各类账单原始件解析成统一记录 `{date, counter, amt(支出为正), cat, src}`，写入对应卡明细表。

## 通用解析规则

1. **只统计指定起始月**（当前2026-03起），更早一律丢弃不追问
2. **退款处理**：微信"已全额退款/对方已退还"→跳过；"已退款(¥X)"→按净额；支付宝"退款成功/交易关闭"→跳过；零钱收入侧退款回冲不计
3. **支出为正**符号统一；**7623 eml 例外：正数=消费负数=冲正**（必查符号再入库）
4. 卡号别名：8551=9876老尾号（支付宝8551渠道全跳，9876流水已含）；4738=7623附属卡；6893=HK Pulse卡RMB子账户（跳，账单已含）；9527=9876微信渠道名
5. **边界补录**：微信导出止日 > 银行流水止日 时，用微信渠道补银行缺失段（如9527补9/14后、8316补9/17后）

## 入库流程

1. 解析 → 临时 JSON（`_xxx_txns.json` 存档目录，复跑可幂等）
2. 大批量重写卡表：先写备用表 SHEET_hsgpLC → 核对 → clear+写正式表
3. 同步勾稽：账单应还金额 vs 周期内明细合计（记入"信用卡月账单汇总验算"SHEET_D0xECl）
