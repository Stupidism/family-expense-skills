# 三分类法引擎

每笔交易同挂三套分类 + 事件标签：`catGB/catQS/catZFB = [主类, 子类]`、`event = [婚礼, 配偶手术及康复, 旅游...]`（一笔可多事件，如4月高铁=交通+婚礼）。

## 三套主类体系

### GB（国家统计局八大类+扩展）
标准8：食品烟酒/衣着/居住/生活用品及服务/交通通信/教育文化娱乐/医疗保健/其他用品及服务
扩展：家庭服务(育儿嫂)｜孝亲馈赠｜婚礼专项｜创业经营｜房贷月供｜保险保障｜心理健康｜婴儿用品｜亲情往来(非消费)｜退款对冲

### QS（记账软件风格·随手记式）
食品酒水/衣服饰品/居家物业(含房贷+育儿嫂)/行车交通(含停车)/交流通讯/休闲娱乐/人情往来/心理健康/医疗保险/金融保险/购物淘宝/日常用品/创业经营/退款冲销/资金流转/信用卡账单

### ZFB（支付宝年度账单风格）
餐饮美食/购物消费/交通出行/娱乐休闲/生活日用(含房贷水电物业话费育儿嫂)/人情往来/医疗健康/心理健康/教育文化/转账红包/退款/信用卡还款/公益捐赠/创业经营/其他

## 关键映射差异（易错点）

- 停车费：GB=居住｜QS/ZFB=交通
- 房贷：GB=独立扩展类｜QS=居家物业｜ZFB=生活日用
- 育儿嫂：GB=家庭服务｜QS=居家物业｜ZFB=生活日用
- 公益：GB=其他·公益捐赠(计入)｜ZFB=公益捐赠独立
- 物业费小区：GB=居住；三套子类都带"物业费"

## 自定义类别的三种添加方式

### 方式A·表格改一笔（最常用，零代码）
在腾讯明细表给目标行的分类列直接选/填新值：
- 点 K/M/O（主类）下拉 → 若选项不存在则手输新主类名（下拉允许手输任意值）
- 或 L/N/P（子类）选"主类｜子类"，需要新组合时手输 `新主类｜新子类`
- 或 R 列填 `新主类｜新子类`（三套同步）
然后跑 `apply_review.py` 读回 → 新类别自动进入数据；重跑 gen_dashboard.py 后下拉选项集自动包含新类别（选项集从数据生成）

### 方式B·批量建新类（一次性归集，脚本层）
适合"把XX单独拆出来"类需求（如心理健康、婴儿用品都是这么建的）：
1. 确定触发条件：商户关键词/人名/金额区间/支付账户
2. 写点查脚本（模板=apply_v101.py）：遍历 `_v10_base.json`，命中行改 cat1/cat2 + catGB/catQS/catZFB 三套 + 可选 event 标签
3. 跑管线：build_recon.py → gen_rangelinks.py → gen_dashboard.py → 同步表格
4. 重跑 set_dropdowns.py + set_grouped_dropdowns.py 刷新下拉选项

### 方式C·永久规则（引擎层，一劳永逸）
新账单月自动归类：在 multi_scheme.py 的 CAT_MAP/refine/关键词池加规则（如模型代购人=GLM会员规则，当月无命中后续命中即归）。
注意：引擎规则只影响新解析行；存量行用方式B点查。

### 建类判断（跟用户确认过的口径）
- 八大类能装 → 装标准类（加子类即可）
- 装不下且月度复发 → 独立扩展主类（如育儿嫂/房贷/心理健康/婴儿用品）
- 一次性事件 → 用事件标签（event）而非新类（如婚礼）
- 三套分类法可不同归属（停车费GB=居住/QS=交通），建类时三套一起定

## 复核回路

用户在明细表 R 列（下拉）填：
- `确认` / `错误` → review 标记
- `主类｜子类`（子类下拉选项格式）→ 三套分类同步写
- `GB主类=xx` / `GB=主类/子类` → 单套覆盖
→ 跑 `apply_review.py`（工作区）读回 JSON → 重跑管线生效

## 引擎脚本（工作区）

`multi_scheme.py`（v9三分类）→ 零钱逐笔替换 → `_v10_base.json` → `build_recon.py`（对冲标注）→ `_v10_rows.json`
新增定案规则时：改 multi_scheme.py 的映射 + 对既有行跑点查更新（如 apply_v101.py 模式），保持三套同步
